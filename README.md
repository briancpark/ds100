# DS 100

DS 100 is Principles and Techniques of Data Science at UC Berkeley. I took this offering in Spring 2021 under Andrew Bray and Joseph E. Gonzalez. This repo contains my development setup and notes.

## Setup

Simply create a Conda environment and install the correct dependencies. There are a lot of Python packages that are used in this course, so it may be the case that some will break. This course solely uses Jupyter Notebooks for all the assignments.

```sh
conda create -n ds100 python=3.9
pip3 install -r requirements.txt
jupyter lab # or jupyter notebook
```
